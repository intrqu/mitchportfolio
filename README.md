# Mitch Harsch Tattoo

Open `index.html` in a browser. The site runs directly from these files and can also be uploaded to a static web host. Google Fonts improves the typography when available. Local font fallbacks cover offline use.

## Replace the preview content

- In `index.html`, replace the sample portfolio images and link targets with actual tattoo photos. Update captions and alt text to describe the new work. Keep the lightbox markup and the link classes for the gallery interaction.
- Replace the portrait placeholder with an image and meaningful alt text. Add the artist’s biography and studio location.
- To add Instagram photos, place six permission-cleared images in `assets/instagram/` and replace the placeholders inside `#instagram-grid` in `index.html` with links to their original Instagram posts. Use descriptive `alt` text for every image. Do not add photos without Mitch's permission.
- The inquiry form submits to FormSubmit, which emails submissions to `mitchharsch@gmail.com`. Confirm the recipient with FormSubmit after the first submission. FormSubmit processes the submitted contact details; the form requires no private credentials in this repository.

The hero still life and portfolio mockups are original AI-generated preview imagery. The portfolio samples do not represent tattoos by Mitch Harsch.
